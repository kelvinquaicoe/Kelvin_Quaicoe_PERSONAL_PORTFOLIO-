# Kelvin Quaicoe — Personal Portfolio

A responsive personal portfolio showcasing my software engineering experience, research, projects, technical skills, and education.

**Live site:** Once GitHub Pages is enabled, the portfolio will be available at:
`https://kelvinquaicoe.github.io/comp163-PERSONAL-PORTFOLIO-/`

## Built with
- Semantic HTML
- CSS (responsive layout, mobile navigation, reduced-motion support)
- Vanilla JavaScript

No build step or package installation is required.

## Run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/kelvinquaicoe/comp163-PERSONAL-PORTFOLIO-.git
   cd comp163-PERSONAL-PORTFOLIO-
   ```
2. Open `index.html` in your browser. For local development, you can also run a simple server:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`, then save.
4. After GitHub Pages finishes deploying, open the site URL shown on the Pages settings screen.
